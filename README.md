# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create notes, organize them into categories, search their notes, delete notes, and keep their notes saved between browser sessions using localStorage.

## Features

- Add new notes.
- Organize notes into Personal, Work, and Study categories.
- Delete individual notes.
- Search notes without case sensitivity.
- Validate empty notes and notes longer than 200 characters.
- Save notes using localStorage.
- Display the total number of notes.
- Responsive design for desktop and mobile devices.

## How to Run Locally

1. Download or clone this repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in your web browser.
4. You can also use Live Server in VS Code.
5. Start adding, searching, and deleting notes.
